CLDC - Pacote para XAMPP

1. Instale o XAMPP.
2. Copie a pasta CLDC_XAMPP para:
   C:\xampp\htdocs\
3. Renomeie a pasta para:
   CLDC
4. Inicie o Apache no XAMPP.
5. Abra no navegador:
   http://localhost/CLDC/

Estrutura:
CLDC/
├── index.html
├── .htaccess
├── css/
│   └── style.css
└── js/
    └── app.js

Login demonstrativo:
Utilizador: admin
Palavra-passe: cldc123

Nota:
Esta versão ainda é apenas frontend. O login e os dados armazenados no navegador
são demonstrativos. Na próxima etapa podemos ligar o site ao banco de dados.
