# CLDC — Frontend

Projeto inicial do site da Consultoria Linguística, Demócrito — Comunicação, Línguas e Desenvolvimento.

## Estrutura
- index.html
- css/style.css
- js/app.js

## Funcionalidades
- Design responsivo para computador e telemóvel
- Página inicial
- Formulário de formação
- Formulário de consultoria
- Formulário de candidatura
- WhatsApp
- Área administrativa demonstrativa
- Login de demonstração
- Geração de PDFs no navegador
- Armazenamento temporário dos formulários no localStorage

## Login demonstrativo
Utilizador: admin
Palavra-passe: cldc123

IMPORTANTE: esta autenticação é apenas para protótipo. Não deve ser usada como segurança real em produção. A próxima fase deve ligar o frontend a um backend e base de dados.

## Como executar
Abra o index.html num navegador moderno.

A geração de PDF utiliza jsPDF através de CDN, por isso é necessária ligação à internet para carregar a biblioteca.
